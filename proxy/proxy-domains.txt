# --- Google, all of it ----------------------------------------------------
# The whole family, not product by product. Google's certificates cover all of
# *.google.com, *.googleapis.com, *.gstatic.com and more, so browsers send a
# request for one Google host over a connection already open to another
# (connection coalescing). sing-box routes a connection by the name it saw when
# it opened, so with only some Google hosts proxied, NotebookLM or Gemini
# requests ended up on a direct connection opened for search or accounts, and
# Google saw Belarus. This covers Gemini, gemini-cli (cloudcode-pa and
# generativelanguage.googleapis.com), NotebookLM, AI Studio and YouTube's API.
google.com
googleapis.com
gstatic.com
googleusercontent.com
ggpht.com
gvt1.com
gvt2.com

goo.gl
